# 網頁改版：清楚易讀的 Liquid Glass 介面

2026-09-19，分支 `feat/clay-responsive-web`。沿用 Python、Jinja2 與原生 CSS／JavaScript；這次處理四語首頁、來源頁、文章頁及撤回頁。依最新方向，視覺從 Clay 調整為低彩度、輕量的 Liquid Glass，保留既有閱讀流程。

## 1. 閱讀與操作

首頁簡短說明網站用途，並直接呈現最新三則真實消息，取代原本的 glass-scene 裝飾。最新一則包含標題、摘要、來源與時間，另兩則提供標題、來源與時間；標題連到對應報導。此區塊排除已被新版取代的報導，手機也會直接顯示。下方「依日期瀏覽」保留完整報導、日期分組、搜尋及篩選；桌機右側提供網站說明及 RSS 入口，手機依閱讀順序排成單欄。

首頁主按鈕與 RSS 按鈕使用內容寬度，依最新要求將高度從 56px 降至 44px、上下留白 10px；水平留白與圖示間距恢復原本設定。手機及平板不再隱藏整組操作按鈕，也不強制撐滿整列。側欄以統一 grid gap 排列主題標籤、網站說明及訂閱卡：桌機 26px、手機／平板 24px，不再僅為訂閱卡添加上邊距。

搜尋位於桌機 masthead 中央，手機改為導覽列第二行；右側保留語言及外觀兩個小型選單。語言選單直接選 English／繁體中文／日本語／한국어；外觀選單直接選淺色／深色／跟隨裝置，未儲存偏好時預設跟隨裝置。語言依目前網址顯示。選單以原生 details 實作，支援鍵盤、Escape、點外側關閉，並標示目前選項。語言選項使用普通連結，保留搜尋條件但清除文章與區段錨點。已移除所有位置儲存、捲動還原及自動捲動；選新語言時正常載入頁面。語言導覽不套用文章卡片的跨頁轉場，選目前語言只關閉選單。

搜尋在瀏覽器內過濾目前頁面的標題、摘要、作者及來源，不呼叫搜尋 API。支援多關鍵字與 Unicode 正規化；有篩選條件時首頁介紹收起，直接顯示結果。「篩選與排序」提供最近 7／30／90 天、自訂起訖日期、主題、作者、來源及新舊排序，不同條件取交集。日期以報導發布的台北日期計算，起訖日皆包含在內。

條件保存於網址的 `q`、`period`、`from`、`to`、`topic`、`author`、`source`、`sort` 參數，重新整理與切換語言會保留；分享或重新導覽時網址會包含這些條件。搜尋框的清除與 Escape 只清除關鍵字，「清除所有條件」則重設所有篩選。這是目前頁面的搜尋，首頁仍受原本最近 300 篇的範圍限制；文章詳情頁的搜尋會返回首頁搜尋。

主題採保守的關鍵字自動分類：活動、程式開發、開放資料、學習教育、社群、資訊安全及其他，可同時屬於多個主題；介面明示為自動分類。規則使用已公開內容，不呼叫模型，也不改動原始報導。作者以穩定帳號身分區別，遇到同名時加上來源，仍無法區別時使用序號。

外觀可選淺色、深色或裝置設定。偏好存在本機 `localStorage`；瀏覽器禁止儲存時，當頁仍可切換。裝置主題變更及其他分頁的設定變更會同步。停用 JavaScript 時，文章、四語導覽、RSS 與外部來源連結仍可使用，配色跟隨裝置。報導卡不再提供原文展開區塊，完整原文請透過外部來源連結閱讀。

點擊報導圖卡及原文圖片，會在同一頁開啟圖片浮層，不跳轉圖片網址。橫式圖卡支援指標傾斜與邊緣虹彩；關閉按鈕、Escape、點擊外部及圖片下載維持原生操作。關閉後回到原本焦點及閱讀位置。停用 JavaScript 時圖片仍直接顯示於文章中。

英文仍使用英文報導圖卡，其他語言保留原文圖卡。網站產生各自快取的深色／淺色 PNG，文字、底色及分隔線與網站配色一致，頭像維持原色；縮圖、浮層及下載同步。RSS、社群預覽與 Telegram 仍使用預設淺色版本。圖卡文字、預設新聞排序、翻譯規則與送達流程沿用原有實作。

作者列會使用與圖卡相同的真實頭貼，經既有安全下載流程快取成站內 PNG；不讓讀者直接連到外部頭貼服務。無照片或下載失敗時才回退名字首字。頭貼放在 cards 目錄，撤回文章的既有媒體清除流程也會刪除它。

圖卡採用自行撰寫的 CSS 傾斜／光澤，視覺參考 [Pokémon Cards CSS](https://github.com/simeydotme/pokemon-cards-css)，未引入卡片素材或動畫套件。浮層固定橫式比例以避免載入時變形，圖片使用 contain 保留全部內容，並提供四語載入與失敗狀態。減少動態、減少透明度、強制色彩時停用裝飾。

## 2. 設計規格

| 規格 | 實作 |
|---|---|
| 色彩 | 淺色冷灰底 `#eef2f6`、深色底 `#11161e`；文字與表面使用集中式語義 tokens |
| 材質 | 半透明分層表面、柔和背景光、局部背景模糊與窄邊緣高光；透鏡效果以 CSS 近似，並非物理折射模擬 |
| 字體 | DM Sans 400–700 用於標題與內文，CJK 使用裝置字型；既有 Nunito 資產保留但不套用於新介面 |
| 尺寸 | 最大容器 1200px；卡片 32px 圓角、內層 24px、控制項 20px；互動目標至少 44×44px |
| 響應式 | 1100／900／640／440／360px 斷點調整閱讀欄、導覽、裝飾及按鈕；四語 DOM 閱讀順序保持一致 |

字型原始來源為 Google Fonts 的 [Nunito](https://fonts.google.com/specimen/Nunito) 與 [DM Sans](https://fonts.google.com/specimen/DM+Sans)；OFL 授權隨字型放在 [assets/fonts](../assets/fonts)。產出站台會包含這些檔案，讀者不需連線 Google Fonts。

玻璃導覽列依捲動量調整透明度及模糊；閱讀卡維持較高不透明度，避免背景干擾文字。精確指標移動時，表面局部高光跟隨游標。減少透明度、強制色彩及不支援背景模糊時，使用實色表面。

深淺色使用 CSS [`light-dark()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/light-dark)，適用支援 Baseline 2024 的現代瀏覽器。避免首屏主題閃動的 `theme.js` 會在樣式載入前套用已儲存的選擇。

| 搜尋、文案與建站 | [reading.js](../rep0rter/templates/reading.js)、[topics.py](../rep0rter/topics.py)、[i18n.py](../rep0rter/i18n.py)、[site.py](../rep0rter/publishers/site.py) |
| 撤回頁與緊急清除 | [withdrawn.html](../rep0rter/templates/withdrawn.html)、[policy.py](../rep0rter/policy.py) 的 `_withdrawn_page` |

`glass-motion.js` 共用一個 requestAnimationFrame 迴圈，使用阻尼彈簧處理圖片浮層及圖卡傾斜回彈；舊版滑動外觀指示器已移除；沒有動畫時停止排程。60／120 Hz 使用模擬時間驗證彈簧收斂，尚未以實體手機量測 FPS。切換減少動態設定時，立即移至終點。只有圖片傾斜，工具列保持水平；已移除標題列拖曳關閉，避免誤拖。觸控按住卡片可改變光澤，放開／取消後回正，不攔截瀏覽器縮放。閱讀報導時的跨頁報導卡使用漸進增強的 View Transitions，不支援時維持普通導覽；參考 [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40view-transition)。

作者、來源及自動主題 metadata 均保留在可移除的文章區塊內，篩選選項由仍存在的文章即時建立；不另產生可能殘留被撤回身分的全域索引。最新消息摘要以報導 ID 標記，緊急撤回會同步移除對應摘要，全部移除後收起整個摘要區塊。來源頁的固定標題使用通用文案。即使完整建站失敗，緊急撤回仍可清除內容並顯示套用主題的告示，不依賴 Jinja2 重新渲染成功。

## 4. 驗證

主按鈕及卡片間距修正：320／390／768／900／1024／1440px × 四語 × 深淺色，共 **48 組瀏覽器情境通過**，確認主按鈕可見、可點擊、保留觸控高度、無水平溢出，卡片間距符合各尺寸設定。完整 Python 測試 **714 passed（15.82 秒）**。文字動畫依最新要求恢復優化前版本，播放期間暫停捲動，見 [主題動畫說明](theme-animation.zh-TW.md)。

最新消息更新後，完整測試為 **524 passed（13.91 秒）**。獨立 Chromium 完成四語 × 深淺色 × 320／390／768／1440px 共 32 組驗證：最新三則與實際報導一致、第一則標題位於初始視窗、無水平溢出，搜尋可收起並恢復摘要區塊。另驗證手機同頁切換語言保留摘要閱讀位置、報導連結保留語言，未出現瀏覽器程式錯誤。這些為模擬視窗測試，尚未使用實體手機驗證。

既有網站、RSS、四語、原文、修訂、退出及發布測試持續保留。新測試包括 60／120 Hz 彈簧收斂、取消及減少動態切換、圖片浮層資產與退出清除、外觀儲存與系統變更、搜尋及復原、本機字型／JS 資產、無 JavaScript 降級，以及不重建站台的退出隱私回歸。

整合回專案後，Python 3.12 完整測試結果為 **388 passed（8.24 秒）**，`git diff --check` 通過；本機文件連結在前次改版另驗證 69 條皆有效。

視覺與操作使用獨立 Chromium 驗證，未使用個人瀏覽器的登入狀態。四語首頁共 20 組尺寸：320、375、768、1024、1440px；文章及撤回頁另檢查 24 組。已確認無水平溢出、互動目標尺寸、鍵盤焦點、跳至內容、原文展開、搜尋與主題切換。另檢查停用 JavaScript、儲存受阻及減少動態設定。先前 Liquid Glass 更新曾檢查 8 組響應式導覽與 32 組圖片浮層情境（四種尺寸、四語、深淺色），確認網址不變、三種關閉方式、焦點還原、捲動位置、下載及原文圖片；當時亦檢查標題列拖曳關閉；橫式圖卡版已移除此操作，改以圖卡傾斜回彈與觸控取消測試。額外 16 組一般／減少動態、深淺色與尺寸矩陣全部通過，包含開啟途中更改動態偏好及四語連續開關，未出現瀏覽器程式錯誤。

搜尋導覽更新另完成 32 組四語 × 深淺色 × 320／390／768／1440px 的瀏覽器檢查，涵蓋置中搜尋、兩個控制項、篩選展開、圖片浮層及無 JavaScript 語言導覽。組合篩選另驗證作者＋來源＋主題＋日期＋關鍵字、網址重載、跨語言保留條件、錯誤日期、排序及詳情頁返回首頁搜尋，未出現程式錯誤。

依最新要求移除語言位置還原後，8 組桌機／手機與四語導覽逐幀檢查通過：正常新頁從頁首顯示、沒有程式捲動呼叫、沒有文章錨點；選目前語言不重新載入。舊的位置還原測試已換成禁止捲動與位置儲存的回歸測試。語言／外觀選單另通過 32 組尺寸、配色、語言檢查，涵蓋裝置預設、直接選取、Escape、點外側關閉及無 JavaScript 語言導覽。

新配色在基本閱讀表面取樣：次要文字淺色至少 5.62:1、深色 8.15:1，主按鈕白字 6.87:1。這是本次涵蓋情境的驗證，並非完整 WCAG 認證。減少動態與對比依據：[W3C C39](https://www.w3.org/WAI/WCAG21/Techniques/css/C39.html)、[W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

macOS 本機原有圖卡測試的字型預設路徑不存在。本次透過暫存 pytest 設定使用現有 `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`，未修改圖卡字型解析程式。Linux CI 原本會安裝 `fonts-noto-cjk`。

## 5. 預覽與發布範圍

開發預覽使用公開網頁快照建立獨立資料庫，再透過真正的建站函式產生頁面；未採集正式資料庫、呼叫模型或推送 Telegram。預覽內容不是新的新聞發布紀錄。

初次改版時，本機 checkout 尚未包含投稿及 Google 登入功能。合併最新 main 時已整合這些功能，保留投稿入口與作者自行投稿標示，並為帳戶及投稿表單加入適用於深淺色與手機的樣式。帳戶頁維持既有禁止 JavaScript 的安全政策，外觀依裝置設定。推送 main 後，由既有部署流程等待該提交的 CI 通過，再進行部署；實際上線狀態須另行確認。

下一步（1 分鐘）：開啟本機預覽，在中央搜尋框輸入字詞，再展開「篩選與排序」選擇作者或日期。

最新的按鈕圓形揭露、全域符文與 `?lang=` 同頁語言切換，已取代本文前述原生跨頁語言流程。修改檔案及驗證結果見 [主題動畫預覽](theme-animation.zh-TW.md)。

## 5. 登入與帳號介面

登入入口改用原頁 `dialog`，共用 `_login_card.html`；`/auth/sign-in` 提供無 JavaScript 時仍可操作的獨立頁。介面提供繁中、英文、日文、韓文，配色沿用主站 tokens。登入視窗支援 Escape、外側點擊、焦點返回與載入失敗重試，顯示期間停止背景捲動。帳號頁的共用版型為 `_account_base.html`，並在 CSS 前載入既有 `theme.js`，同步手動偏好與裝置配色。

Google 驗證保留 CSRF、OIDC state／nonce、PKCE 與可撤銷工作階段。回程限制為首頁、文章、來源及標籤閱讀頁，保留原網址的語言、搜尋條件及錨點。瀏覽器可以使用 sessionStorage 時，等待初始語言載入完成後再恢復閱讀高度；儲存受阻仍可登入及返回原網址。從投稿或專案管理開始登入時，保留原本目的地與投稿標籤。Google 登入本身仍需前往 Google 完成驗證。

前端維護 `client/src/account.ts`，以 `npm --prefix client run build` 產生提交的 `account.js`；`login.css` 管理登入卡片／浮層，`account.css` 管理投稿與專案表單。新增靜態資產由既有建站流程一併產出。帳號頁 CSP 只允許指定的主題與帳號腳本，不開放行內腳本。

`python scripts/verify-login-ui.py --url http://127.0.0.1:8766` 可檢查有登入設定、四語資料的本機預覽。檢查不提交 Google 表單，涵蓋 320／390／768／1440px、深淺色、鍵盤、閱讀位置、延遲語言載入、圖片浮層、重試、儲存受阻與停用 JavaScript。真實 Google 帳號登入及實體手機仍需另行驗收。

## 6. 共用入口與進場動態

主站「登入」和「寫文章」現在使用同一個登入浮層；差別只在驗證完成後的目的地。已登入者點「寫文章」會進入投稿表單。直接開啟 `/write` 或停用 JavaScript 時仍顯示同一張登入卡片的完整頁面。

帳號頁補回主站品牌 Logo、favicon、導覽圖示及四語選單。`account_copy.py` 集中管理投稿與專案表單翻譯，使用者的稿件保持原文。切換語言會保留欄位、勾選狀態、投稿識別與目前捲動高度；請求失敗時留下原稿，快速操作以最後選擇為準。不把表單草稿送入語言切換的 GET 請求。

`client/src/entry-motion.ts` 與 `entry-motion.css` 負責首頁進場：同一分頁首次進入首頁時，品牌先以 650 ms 的柔和光學揭露置中顯現，保持清晰 1.2 秒，再以 850 ms 的臨界阻尼彈簧縮回導覽列原位置。薄玻璃襯底在歸位前段退去，完整流程約 2.7 秒；真實 Logo 與文字負責呈現，沒有影片或新增動畫套件；期間鎖定捲動與背景互動。主題沿用首次繪製前的設定。重載、返回、搜尋／篩選／錨點連結、登入回程和減少動態設定跳過進場。Escape、視窗尺寸變動、離頁或最長 4.5 秒保險計時均可解除，不依賴永久儲存。

Filter & sort 保留原生 details 與鍵盤操作，開啟、收合及自訂日期區塊的高度變化改用可中斷的彈簧動畫；快速反向操作接續目前高度與速度。動畫結束清除暫時樣式，減少動態時直接切換。日期區塊旁的 `edition-badge` 已移除，語言狀態只保留在選單內。

開發時可將 `docs/brand-motion-preview.html` 複製至本機產出的網站目錄，以同源 URL 開啟；提供手機／平板／桌機、深淺色與重播控制。預覽載入真實首頁，僅在預覽頁中清除該分頁的品牌播放紀錄，不改變正式首頁的播放政策。此檔不由網站建置流程發布。

窄於 1100px 的 masthead 將投稿、登入、語言與外觀維持同一排 44px 圖示操作，文字名稱保留於 aria-label/title；搜尋在下一排。極窄手機縮小品牌字樣，保留四個完整點擊區域。開場使用原生模態 dialog 提供右上角「略過」、右下角「下次不再顯示」，鍵盤焦點留在可操作範圍；自動歸位時按鈕以 240 ms 淡出，手動略過／不再顯示則讓按鈕、品牌與遮罩一起淡出後清理。淡出期間停用按鈕以防重複操作；關閉後恢復品牌焦點且不捲動。後者以 localStorage 的 `rep0rter-brand-dismissed` 記住這個瀏覽器的選擇；儲存受阻時仍可正常關閉本次開場。
